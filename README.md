# insanyya-dev.github.io

Root of the Insanyya developer website (GitHub Pages user site).

- `app-ads.txt`: authorised ad sellers for every Insanyya app. One file for all apps on the developer account:
  each app's Play Console store listing must have **Website = https://insanyya-dev.github.io**.
  Moved here from app-ads-txt.com on 2026-11-20 (same two lines).
- `index.html`: home page (all apps, Free/Premium links, privacy, contact), in the Food Additives redesign style.
- Privacy pages stay in the `Privacy` repo (https://insanyya-dev.github.io/Privacy/...).
